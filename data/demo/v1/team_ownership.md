# Service Ownership Register

Each production system has exactly one owning team. The owning team's lead is accountable
for incidents, remediation and change approvals affecting the system.

| System | Owning team | On-call rotation |
|---|---|---|
| Document Processing API | Platform Engineering | platform-primary |
| Vector Index Service | Platform Engineering | platform-primary |
| Claims Pipeline | Claims Engineering | claims-primary |
| Local Inference Service | Edge Infrastructure | edge-primary |
